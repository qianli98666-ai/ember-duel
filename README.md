Ember Duel is a turn-based card duel against the Ashen Foe: summon champions that strike at the end of your turn, raise guard shields to soak the foe's blows, and spend a growing pool of ember on spells that burn, mend or draw — first duelist to fall from 30 life loses. To play, open `game/index.html` in a desktop browser; it runs offline from these files alone, with mouse and keyboard (click a card or press 1-7, Enter ends the turn).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
